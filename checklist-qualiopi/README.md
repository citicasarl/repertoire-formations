# Checklist de préparation Qualiopi

Outil HTML/CSS/JS autonome, sans serveur, pour préparer un auto-diagnostic des 7 critères et 32 indicateurs Qualiopi.

## Utilisation
Ouvrir `index.html` ou publier le dépôt via GitHub Pages (Settings > Pages > Deploy from a branch > main / root).

- Choisir les catégories d'actions et préciser le périmètre.
- Corriger manuellement l'applicabilité de chaque indicateur selon le guide officiel.
- Renseigner l'état et les preuves / actions restantes.
- Imprimer en PDF, exporter CSV, sauvegarder et restaurer en JSON.
- La progression est enregistrée localement dans le navigateur (localStorage).

## Important
Les intitulés sont des résumés, les règles d'applicabilité automatiques sont indicatives. Vérifier le guide officiel Qualiopi et ses mises à jour : https://travail-emploi.gouv.fr/IMG/pdf/guide_de_lecture_qualiopi_v9_du_8_janvier_2024-2.pdf

Outil indépendant, non officiel, sans valeur de certification.
